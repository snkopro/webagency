# Sections mises de côté

`sections-de-cote.html` contient deux sections retirées du site, qu'on pourra réutiliser :

- **Panneau à texte révélé** : grand bloc arrondi où la phrase s'éclaire mot par mot au scroll.
- **Avant / après** : un vieux site se transforme en site moderne avec une ligne qui balaie l'écran.

Ouvre le fichier dans un navigateur pour les voir en action. HTML, CSS et JS sont dans le même fichier.
