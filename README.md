# webagency

Site de l'agence de Mathias — HTML/CSS/JS statique, publié sur GitHub Pages :
https://snkopro.github.io/webagency/

## Structure
- `index.html` — page d'accueil (hero, services, réalisations, méthode, à propos, FAQ, contact)
- `mentions-legales.html`, `404.html`
- `styles.css`, `script.js`, `fonts/` (polices auto-hébergées)

## À compléter
- Photo (hero + à propos), projets, email / téléphone, réseaux sociaux
- Formulaire : coller l'URL Formspree dans `FORM_ENDPOINT` (script.js)
- Mentions légales : SIRET, adresse
